  4. Theory of Computing Projects

    1. Designed an efficient NFA simulation engine to process input strings without full DFA conversion or exponential backtracking.

    2. Developed a high-performance regular expression matching engine (similar to Unix grep) that parses regular expressions, converts them into Non-Deterministic Finite Automata (NFAs), and executes linear-time string matching.

    3. Built a Unix sed-style stream editor and demonstrated its Turing-completeness by compiling Turing machine specifications into executable sed scripts.

    4. Extended a custom regular expression engine to support backreferences—pushing its matching capabilities beyond context-free languages—and proved the problem's NP-completeness by implementing a SAT solver via polynomial-time reduction.

    Python · Bash · Makefile · Theory of Computing

  5. pqsh (Process Queue Shell):
